# Product

## Register

product

## Platform

web

## Users

Pantrify is for two partners sharing a household. Either person may notice an item running low, add it immediately from their phone, or use the same list while shopping. Both need to trust that the list reflects the household's current needs without checking by text.

## Product Purpose

Pantrify provides one reliable shared grocery list where either partner can add products as they run out, check them off while shopping, and see what was purchased previously. Success means fewer forgotten products, duplicate purchases, and messages asking what needs to be bought.

## Positioning

A shared household list that remembers what you buy, so running out never turns into another text message.

## Brand Personality

Colourful, practical, and structured. The interface should feel crisp and immediately understandable, with compact rows, clear black typography, restrained category colours, and minimal decoration.

## Anti-references

Pantrify should not feel beige, cute, corporate, dark, or cluttered. It should avoid ornamental styling, excessive visual effects, and dense interfaces that slow down adding or checking an item.

## Design Principles

1. Keep the shared list trustworthy: changes must be clear, immediate, and visible to both partners.
2. Make the common action effortless: adding an item as it runs out should take only a few seconds on a phone.
3. Use category colour to organize, not decorate: colour should make the list easier to scan.
4. Preserve useful household memory: previous purchases and recurring Staples should reduce repeated work.
5. Keep the interface compact and calm enough to use one-handed in a shop.

## Accessibility & Inclusion

Prioritize strong mobile readability, clear touch targets, good colour contrast, and reduced-motion support.
